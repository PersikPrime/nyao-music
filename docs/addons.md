# Дополнения Nyao Music

Дополнение — папка с `manifest.json` и файлом JavaScript. Оно работает внутри Nyao Music на компьютере и
умеет ровно то, что перечислило в манифесте и что разрешил человек.

Сейчас API обкатывается: свои дополнения запускаются только в **Nyao Music Red**, из папки для разработки.
Каталог и установка из файла появятся позже. API может меняться, пока в манифесте `"nyao": 1`.

## Быстрый старт

1. Nyao Music Red → Настройки → Дополнения → «Открыть папку».
2. Создай там папку, например `quotes`, и два файла:

`manifest.json`
```json
{
  "id": "takko.quotes",
  "name": "Строка из песни",
  "version": "1.0",
  "nyao": 1,
  "description": "Показывает уведомление с первой строкой песни.",
  "permissions": ["track", "lyrics", "ui.toast", "ui.trackMenu"]
}
```

`addon.js`
```js
nyao.ui.trackMenu.add({ id: 'first', title: 'Первая строка' }, async (track) => {
  const lyrics = await nyao.lyrics.get(); // текст того, что играет сейчас
  nyao.ui.toast(lyrics ? lyrics.lines[0].text : `У «${track.title}» нет текста`);
});
nyao.player.onTrack((track) => nyao.log('играет', track && track.title));
```

3. «Перечитать» → включи дополнение. Перед включением Nyao Music покажет, что оно сможет.
   Ошибки и `nyao.log` видны в «Журнале» на карточке дополнения.

## Манифест

| Поле | Что это |
| --- | --- |
| `id` | `автор.название` латиницей, строчными. `nyao.*` занято встроенными |
| `name`, `version`, `description`, `author` | Показываются в карточке. Версия — числа через точку |
| `nyao` | Версия API, сейчас `1` |
| `main` | Файл с кодом, по умолчанию `addon.js` |
| `permissions` | Список прав, см. ниже. Неизвестное право — дополнение не запустится |
| `page` | Папка с локальной страницей (нужно право `page`) |
| `settings` | До 12 настроек: `{ key, type: "toggle" \| "select", label, default, options }` |
| `icon`, `color` | Значок (`scrobble`, `overlay`, `music`, `lyrics`, `bell`, `link`, `puzzle`) и цвет `#RRGGBB` |

## Права

| Право | Что даёт | Куда уходят данные |
| --- | --- | --- |
| `track` | `nyao.player.get()`, `onTrack`, `onState` — трек, обложка, позиция, очередь из 5 треков | остаются на устройстве |
| `control` | `play`, `pause`, `toggle`, `next`, `prev`, `seek`, `setVolume`, `like` | на устройстве |
| `lyrics` | `nyao.lyrics.get()` → `{ synced, lines: [{ time, text }] }` или `null` | на устройстве |
| `history` | `nyao.history.recent(n)` — до 200 прослушиваний с этого компьютера | на устройстве |
| `ui.trackMenu` | до 3 своих пунктов в меню трека | на устройстве |
| `ui.toast` | уведомления с подписью дополнения, не чаще 5 в минуту | на устройстве |
| `page` | локальная страница на `127.0.0.1` (например, оверлей для OBS) | видна только с этого компьютера |
| `net:домен` | `nyao.net.fetch()` к этому домену | **уходят в сеть** — в карточке это видно |

Без прав доступны `nyao.settings.get()` / `onChange`, `nyao.storage.get/set` (до 256 КБ на дополнение) и `nyao.log`.

**Права на входы в сервисы не существует.** Пароли, куки и ключи Яндекса, VK, Spotify, Last.fm и аккаунта Nyao
в API не попадают — попросить их нельзя.

## Сеть

Дополнение не может сходить в сеть само: `fetch`, `XMLHttpRequest`, `WebSocket` и остальное в нём выключены.
Единственный путь — `nyao.net.fetch(url, { method, headers, body })`:

- только `https` и только домены из `permissions` (поддомены нужно перечислять отдельно);
- без куки, переадресации запрещены, не чаще 60 запросов в минуту;
- тело запроса до 256 КБ, ответ — текстом до 1 МБ: `{ status, ok, headers, text }`.

## Локальная страница

Право `page` и поле `"page": "page"` в манифесте: Nyao Music отдаёт файлы из этой папки по адресу
`http://127.0.0.1:47840/a/<id>/`. Дополнение публикует данные — `nyao.page.publish({...})` (до 64 КБ),
страница получает их потоком:

```js
new EventSource('__events').onmessage = (e) => render(JSON.parse(e.data));
```

Последние данные одним запросом — `__data`. Страница только читает: управлять плеером через неё нельзя.
Пример целиком — встроенный оверлей для OBS: [`src/addons/nyao.overlay`](../src/addons/nyao.overlay).

## Как устроена защита

- У каждого дополнения своё невидимое окно в песочнице: без Node.js, без доступа к файлам, со своей пустой памятью
  (куки и хранилища приложения ему не видны).
- Код грузится только из папки дополнения; политика содержимого запрещает чужие скрипты, фреймы и запросы.
- Каждый вызов API проверяется в главном процессе по списку разрешённых прав. Кто зовёт, определяется по окну,
  а не по словам дополнения.
- Новая версия попросила больше прав — дополнение не запустится, пока человек не разрешит.
- Упало три раза за минуту — останавливается; плеер это не задевает.

Код: [`src/main/addons`](../src/main/addons) — `manifest.js` (манифест и права), `host.js` (песочница и проверки),
`pages.js` (локальные страницы), `addon-preload.cjs` (объект `nyao`).
