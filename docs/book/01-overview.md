# 1. Что это и как устроено

## Продукт в двух словах

Nyao Music — один плеер для **Яндекс Музыки, YouTube Music, SoundCloud, VK Музыки и Spotify**:
общие лайки и плейлисты, поиск сразу везде, «Моя волна», которая смешивает сервисы, тексты песен,
друзья и «сейчас играет», передача воспроизведения между устройствами.

Все сервисы подключены через **неофициальные** внутренние API (те же, которыми пользуются их сайты
и приложения). Поэтому после обновлений сервисов что-то регулярно ломается — это нормальная часть работы.

## Платформы

| Платформа | Где в репо | Технологии | Минимум |
|-----------|-----------|------------|---------|
| Windows, macOS | `src/` | Electron (сборка castlabs с Widevine), чистый JS без фреймворков | Windows 10 x64, macOS (arm64 и x64) |
| Android | `android/` | Kotlin, Jetpack Compose, Media3 (ExoPlayer) | Android 8.0 (API 26) |
| iOS, iPadOS | `ios/` | SwiftUI, AVPlayer; ставится через SideStore | iOS 17 |
| Android 4.x | `legacy/` | Nyao Legacy — отдельное упрощённое приложение (отложено) | Android 4.0 |
| Сервер | `server/` | Node.js 22 без фреймворков, Postgres 17, Caddy | Docker на Selectel |
| Spotify на ПК | `native/librespot/` | Rust (librespot), экспериментально | — |

## Как части связаны

```
 ┌────────────── устройство пользователя ──────────────┐
 │  Приложение (ПК / Android / iOS)                    │
 │   ├─ провайдеры сервисов ── токены/cookies тут ──►  Яндекс, YT Music, SC, VK, Spotify
 │   ├─ волна (смешивание), плеер, тексты              │
 │   └─ клиент сервера Nyao ───────────────┐           │
 └─────────────────────────────────────────│───────────┘
                                           ▼
                     Сервер Nyao (api.music.withnyao.app)
                     история, «сейчас играет», друзья, профили,
                     зеркало обновлений, сайт текстов, Automator API
                                           │
                     Ретранслятор на Cloudflare (вход Telegram, картинки)
```

Сервер **ничего не играет и ничего не знает о сервисах**: он хранит историю прослушиваний,
профили, друзей, настройки и раздаёт обновления.

## Словарь

| Термин | Что значит |
|--------|-----------|
| **Трек** | Объект `{ id, source, srcId, title, artist, album, duration, cover, … }`. Одинаковый на всех платформах |
| **id трека** | `источник:идентификатор`: `ya:12345`, `yt:dQw4w9WgXcQ`, `sc:98765`, `vk:-2001_456`, `sp:4uLU6h…` |
| **source** | Код сервиса: `ya` Яндекс, `yt` YouTube Music, `sc` SoundCloud, `vk` VK, `sp` Spotify |
| **srcId** | id внутри сервиса (часть после двоеточия) |
| **Провайдер** | Модуль, который говорит с одним сервисом: поиск, лайки, плейлисты, ссылка на звук |
| **Моя волна** | Бесконечная подборка из всех сервисов. Глава 6 |
| **Микс** | Свой плейлист Nyao из треков любых сервисов (`source: 'mix'`) |
| **Аккаунт Nyao** | Вход через Telegram на наш сервер: история, друзья, синхронизация |
| **Nyao Connect** | Пульт: управлять плеером на другом устройстве, «забрать сюда» |
| **Слушать вместе** | Комната: гости слушают то же, что хост |
| **Automator** | Отдельное приватное админ-приложение (репо `PersikPrime/automator`), ходит в `/admin/*` |
| **LyricLabs** | Наш сервис текстов песен: `lyrics.withnyao.app`, живёт в том же сервере |
| **Горячее обновление** | Пакет `.nui` с кодом ПК без установщика. Глава 10 |
| **Шаблонная обложка** | Диск на цвете (`nyao://cover/<id>.png`) для треков без картинки, чаще всего VK |

## Принципы кода

- **Без фреймворков.** Интерфейс ПК — строки HTML + делегирование событий; сервер — свой маленький роутер.
  Меньше зависимостей — меньше того, что ломается и что надо обновлять.
- **Комментарии на русском и про «почему»**, а не «что». Перед нетривиальным местом обычно объяснено,
  какой баг оно чинит. Не удаляйте такие комментарии, если не уверены, что причина ушла.
- **Ошибки сервисов — не исключение, а норма.** Почти все запросы к сервисам обёрнуты в «безопасные»
  вызовы с запасным значением (`safe()`, `bounded()`, `runCatching`): один упавший сервис не должен
  ронять экран.
- **Тесты на чистую логику.** Волна, совпадения треков, тексты, горячие обновления, сервер — покрыты тестами без сети.
  UI тестами почти не покрыт — проверяйте глазами.
