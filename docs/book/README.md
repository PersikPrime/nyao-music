## Три правила, которые нельзя нарушать

1. **Токены и cookies музыкальных сервисов живут только на устройстве.** Сервер Nyao их не видит,
   не хранит и не просит. Любая фича, которой «нужен токен на сервере», — это другая фича.
2. **Ключи и пароли — только в GitHub Secrets.** Не в коде, не в чатах, не в issue.
3. **Одно поведение — три реализации.** ПК (JS), Android (Kotlin) и iOS (Swift) повторяют одну логику.
   Поменяли волну, обложки или формат трека на ПК — проверьте, нужно ли то же на Android и iOS.
   Файлы-близнецы подписаны в комментариях: «перенос src/main/… », «то же на ПК: …».
