# 12. Грабли

Всё здесь уже однажды ломалось. Каждая строка — это чей-то потерянный вечер.

## Безопасность

- **Токены сервисов — только на устройстве.** Ни в логах, ни на сервере, ни в «временной» отладке.
  Логи и тексты ошибок — через `safeDiagnostic()` (ПК), `Diagnostics.kt` (Android): они вырезают токены, cookies и query-строки.
- **Секреты — только в GitHub Secrets.** Не коммитьте `.env`, `lastfm-keys.json`, ключи подписи, не вставляйте их в чаты и issue.
  Если секрет утёк — меняйте его сразу, удаления из истории git недостаточно.
- **Данные в HTML — через `esc()`.** Название трека или ник друга может содержать `<img onerror=…>`.

## ПК

| Симптом | Причина | Что делать |
|---------|---------|-----------|
| «Мои правки не применяются» | Приложение грузит код из горячего обновления `userData/hot/`, а не из репозитория | «Вернуть версию из установщика» в центре обновлений или удалить `hot/` |
| Шаблонные обложки не видны | CSP в `index.html` без `nyao:` в `img-src` | Любая новая схема или домен картинок — в CSP |
| В полноэкранном режиме у трека чужая обложка | Запасной вариант брал обложку текущего трека | Запасной путь — только `coverOf(track)` этого трека |
| YouTube отдаёт 403 | Запрос ушёл через сеть Chromium, заголовки подменены | Всё YouTube — через Node `fetch` (так создан провайдер в `initProviders`) |
| Боковые панели наезжают друг на друга | Открывали новую, не закрыв прежнюю | Открывая панель (`openDrawer`, настройка волны), закрывайте остальные |
| Обработчик стал «тормозить» интерфейс | `render…()` в событии `time` плеера | В `time` — только точечные правки DOM |
| Клик по строке играет не тот трек | Список отрисовали заново под тем же ключом `lists[key]`, а строки старые | Один ключ — один список на экране |
| «Свежесть» волны работает наоборот | Провайдер вернул лайки от старых к новым | `likedTracks()` — **новые первыми**, всегда |

## Волна

- **Настроение знает только Яндекс.** Подмешивание других источников при выбранном настроении даёт «джампстайл в Спокойном».
- **В rotor Яндекса — только его треки.** Смешанная очередь в `waveMore()` уводит «Мою волну» от настроения.
- **Баланс 0% / 100% должен быть жёстким** — иначе люди видят VK при «100% Яндекс» и считают это багом (и правы).
- Меняете формулу в `WavePolicy` — сначала тест в `test/wave.test.js`, потом то же в `WavePolicy.kt`.

## Сервер и сеть в РФ

- **ТСПУ режет исходящий TLS с постквантовым обменом ключей** (`X25519MLKEM768`, включён по умолчанию в новом OpenSSL).
  Соединение просто висит. Поэтому в `server/src/index.js`: `tls.DEFAULT_ECDH_CURVE = process.env.TLS_CURVES || 'X25519:prime256v1:secp384r1'`.
  Похожие симптомы у нового внешнего API с сервера — проверьте это первым делом. С хоста `curl` при этом может работать (у него свои настройки TLS).
- **`oauth.telegram.org` с сервера недоступен** → ретранслятор на Cloudflare. **Worker деплоится вручную**: поменяли `server/cloudflare-worker.js` — вставьте его в Cloudflare и нажмите Deploy, иначе новые маршруты (`/img`) не заработают.
- **Картинки CDN без VPN не грузятся** → `/img` на сервере. Если сервер не смог — `302` на оригинал, чтобы с VPN всё открывалось как раньше. Неудачи кэшируются на 10 минут, иначе один битый хост кладёт сервер повторами.
- **Сервер один на все ветки.** Деплой из `main` откатит маршруты, которые есть только в `nightly` — держите серверный код веток вровень (с 0.8.113 `/wave/mix` и `/wave/mood` есть в обеих).
- **Всё, что должно пережить деплой, — в томе Docker.** Баннеры профилей однажды пропали после деплоя: папки не было в `volumes`.
- **Схема базы выполняется на каждом старте** — только `IF NOT EXISTS`, только в конец `SCHEMA`.

## Релизы и CI

- **Случайный пререлиз в main.** Перенесли коммиты из `dev` вместе с `"channel": "dev"` — в main вышел `-dev`. Перед push в main проверяйте `version.json`.
- **`version.json` запускает все сборки** (ПК, Android, iOS). Не трогайте его в коммитах, которым сборка не нужна.
- **Правка только `docs/` ничего не собирает** — можно спокойно коммитить.
- **YAML workflow**: двоеточие в значении без кавычек (`description: Текст: пояснение`) ломает файл целиком — workflow молча пропадает из списка. Берите строки в кавычки.
- **`set -o pipefail` + `grep`**: `grep` без совпадений возвращает 1 и валит шаг. Добавляйте `|| true`, если «ничего не нашлось» — норма.
- **Зелёная галочка ≠ рабочая сборка.** iOS однажды собирался «успешно» без бинарника внутри `.app`. CI теперь проверяет наличие файла; смотрите размер артефакта.
- **Ключ подписи APK потерять нельзя** — обновление поверх перестанет ставиться у всех пользователей.

## Android

- **`Modifier.size()` в узком родителе молча сжимается.** Аватар в профиле стал овалом: `Box` высотой 64 dp, аватар 120 dp. Для фиксированных размеров — `requiredSize()`, для родителя — `wrapContentHeight(unbounded = true)`.
- **`Repo.resolve()` блокирующий** — его зовёт загрузчик ExoPlayer в своём потоке. Не вызывайте из UI.
- **SoundCloud и VK не кэшируются на диск** (`RoutingDataSource`): у кусков HLS временные ссылки.
- Логику волны, совпадений и текстов держите в соответствии с ПК — расхождения пользователи замечают быстро («на телефоне волна другая»).

## iOS

- `init` в SwiftUI-структурах: нельзя обращаться к `self` в замыкании до инициализации всех свойств — используйте `static let`.
- `Info.plist` генерируется XcodeGen — правки в самом plist перезапишутся, правьте `project.yml`.
- SideStore с бесплатным Apple ID: 3 приложения и 7 дней подписи. «Приложение перестало открываться» — чаще всего истекла подпись.

## Работа с сервисами

- Неофициальные API меняются без предупреждения. Падение одного сервиса не должно ронять экран: `safe()`, `bounded()`, `runCatching`.
- Ответы при сбоях полезно сохранять (как `vk-debug.log`), но **только** через `safeDiagnostic`.
- «Сервис упал у всех» — отметьте его в Automator (статус-страница): приложения перестанут его опрашивать и покажут плашку.
