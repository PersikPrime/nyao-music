# Проверка внешнего входа на ПК

Ветка `feat/external-service-auth` основана на Red 0.10.130. Установщик из релиза 130 содержит исправления лайков. Вход через браузер доступен в сборке ветки.

## SoundCloud

1. Открой https://soundcloud.com/you/apps под аккаунтом владельца, создай приложение Nyao Music и зарегистрируй точный Redirect URI `nyao://soundcloud/callback`. Условия получения API-ключа опубликованы в https://developers.soundcloud.com/docs/api/guide .
2. В Settings → Secrets and variables → Actions репозитория добавь `NYAO_SC_CLIENT_ID` и `NYAO_SC_CLIENT_SECRET`. Секрет нужен только серверу. При входе и обновлении сессии сервер передаёт запрос обмена SoundCloud и возвращает токены настольному приложению. Запись токенов на стороне сервера не предусмотрена.
3. Для проверки на действующем API вручную запусти **Server deploy**, выбрав ветку `feat/external-service-auth`. Это обновит действующий сервер всем пользователям. Для отдельного стенда подними сервер этой ветки с `SC_CLIENT_ID` и `SC_CLIENT_SECRET` и задай HTTPS-адрес стенда в `NYAO_SC_AUTH_BASE` при запуске тестового клиента.
4. Запроси `GET /auth/soundcloud/config` на выбранном API. Ожидается публичный clientId и точный redirectUri. Этот endpoint никогда не должен возвращать секрет.
5. Открой на ПК сборку ветки из GitHub Actions → Desktop → Artifacts или запусти в checkout ветки `npm ci`, затем `npm start`. Закрой другие запущенные копии Nyao. Выбери Настройки → Сервисы → SoundCloud → Войти. После подтверждения в браузере разреши открыть Nyao.
6. Проверь имя аккаунта, совпадение нескольких лайков с сайтом, добавление и снятие одного тестового лайка в обе стороны после перезапуска. Повтори после истечения access token. Проверь отмену входа и переключение аккаунтов. Старая сессия заменяется только после успешного входа.
7. Открой медиатеку с несколькими сервисами. При сбое одного источника другие списки должны появляться, а кнопка «Повторить» должна обновлять только сбойный источник.

## Google / YouTube

1. В https://console.cloud.google.com/ выбери проект Nyao. В APIs & Services включи **YouTube Data API v3**.
2. В Google Auth Platform заполни Branding и Audience. Для внешнего приложения в режиме Testing добавь свой Google-аккаунт в Test users. В Data Access добавь `https://www.googleapis.com/auth/youtube.readonly`.
3. В Clients создай OAuth client типа **Desktop app** и скачай JSON за пределы репозитория.
4. В каталоге проекта выполни `node scripts/google-oauth-check.mjs "/путь/к/client.json"`. Открой напечатанную ссылку в браузере на этом же ПК. После входа терминал должен показать `playlists: OK` и `videos: OK`. Ноль элементов допустим для пустой медиатеки.
5. Для отчёта достаточно двух строк результата или HTTP-кода. URL авторизации, JSON и токены остаются у тестирующего. Проверка читает первую страницу плейлистов и понравившихся видео. Оценка трека и воспроизведение YouTube Music требуют отдельной проверки совместимости.
