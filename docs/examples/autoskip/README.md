# Умный пропуск — пример дополнения

Замечает треки, которые ты листаешь в первые секунды, и после нескольких раз пропускает их сам —
с уведомлением, чтобы было понятно, что произошло. В меню трека есть «Не пропускать автоматически»
и «Всегда пропускать».

Что показывает пример:

- как из потока `nyao.player.onState` понять, что трек пролистали, а не дослушали;
- как управлять плеером (`control`) и не считать собственное переключение «пролистыванием»;
- хранилище `nyao.storage` — память о треках остаётся между запусками;
- пункты в меню трека и настройки из манифеста.

Сети нет: в `permissions` ни одного `net:` — всё остаётся на компьютере.

## Как попробовать

Nyao Music Red → Настройки → Дополнения → «Открыть папку», скопируй туда эту папку целиком
и нажми «Перечитать».
