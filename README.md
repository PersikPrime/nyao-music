# Nyao Music

Личный плеер для Windows, macOS и Android: Яндекс Музыка и YouTube Music в одном окне, общая «Моя волна» с подмешиванием треков YTM, общие лайки и смешанные плейлисты.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm start          # запуск
npm run dev        # запуск с DevTools
npm run dist       # установщик .exe в папке dist/
npm run dist:mac   # .dmg для macOS
npm run bump       # +1 к номеру сборки
```

## Версия

Версия показывается как «0.2 (14)», где 14 — номер сборки. Номер лежит в `version.json` и общий для всех версий:
десктоп показывает его в «Настройках» → «О приложении» и в приветствии, Android берёт его как `versionCode`/`versionName`.
`npm run bump` увеличивает номер и синхронизирует `package.json` (там он записан как `0.2.14` — electron-builder требует такой формат).

## Приветствие

При первом запуске открывается короткое приветствие: что это за плеер → вход в Яндекс и YouTube → характер волны и баланс источников →
(на ПК) статус в Discord → «Запустить волну». Если ты уже входил в аккаунты в прошлых сборках, оно не покажется.
Повторить можно в «Настройках» → «Показать приветствие снова».

## Android

Папка `android/` — нативное приложение на Kotlin + Jetpack Compose в стиле Material 3 Expressive:
главная с карточкой волны, экран «Моя волна» с кнопкой-«печенькой», «Сейчас играет» с цветами из обложки и волнистым прогрессом,
медиатека, плейлисты, поиск по обоим сервисам, вход через окна сервисов, фоновое воспроизведение с уведомлением и кнопками в шторке.
На раскрытом складном/планшете — рейка слева и «Сейчас играет» отдельной панелью справа.

Сборка без Android Studio (нужны JDK 17+ и Android SDK с platform 36):

```bash
cd android
echo "sdk.dir=/путь/к/Android/Sdk" > local.properties   # или переменная ANDROID_HOME
./gradlew assembleRelease        # Windows: gradlew.bat assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk (подписан debug-ключом, ставится сразу)
adb install -r app/build/outputs/apk/release/app-release.apk
```

Как устроено:
- `data/YandexApi.kt` — перенос `providers/yandex.js` (волна rotor, лайки, плейлисты, подпись ссылок на mp3);
- `data/YtMusicApi.kt` — YouTube Music через InnerTube (WEB_REMIX) с cookies и SAPISIDHASH;
- `data/YtStreams.kt` — ссылки на звук у клиентов ANDROID_VR / iOS / visionOS с проверкой и «скамейкой» для клиентов, получивших 403;
- `data/WaveMixer.kt` — та же формула смешивания, что в `wave.js`;
- `playback/` — ExoPlayer + MediaSession; YouTube читается кусками по 4 МБ, при 403 ссылка берётся у другого клиента с той же позиции.

Пока нет (есть на ПК): страниц исполнителей и альбомов, текстов песен, «Моих миксов».

## Два дизайна

Приложение само выбирает дизайн по системе:

- **Windows** — тёмная тема с рейлом слева и полным нижним плеером;
- **macOS** — Liquid Glass: живая лента волны под окном, стеклянный сайдбар и плавающая капсула плеера.

Посмотреть чужую тему можно через переменную окружения: `NYAO_THEME=mac npm start` (PowerShell: `$env:NYAO_THEME="mac"; npm start`).

## Исполнители и альбомы

Страницы исполнителя и альбома собираются из обоих сервисов сразу. Приложение находит ту же сущность во втором сервисе и сопоставляет треки по названию и длительности, поэтому у каждого трека видно, где он есть. Переключатель «Вместе / Яндекс / YouTube Music» (на альбоме — «Играть из») выбирает, откуда играть.

## Вход в сервисы

Настройки → «Войти». Открывается окно входа:

- **Яндекс** — обычная OAuth-страница, после входа токен подхватывается сам.
- **YouTube Music** — страница входа Google. После того как откроется music.youtube.com, приложение забирает cookies сессии и закрывает окно.

Токен и cookies хранятся зашифрованными через DPAPI Windows (`%APPDATA%/Nyao Music/secrets.bin`).

Если Google пишет «Этот браузер или приложение могут быть небезопасны», вставь cookies вручную:

1. Открой music.youtube.com в обычном браузере.
2. Открой DevTools → вкладку Network, обнови страницу.
3. Выбери любой запрос к `music.youtube.com`, скопируй значение заголовка `Cookie`.
4. Вставь его в «Вставить cookies вручную».

## Как устроено

```
src/main/
  main.js              окно, IPC, протокол nyao:// для аудио
  providers/yandex.js  Яндекс: волна (rotor), лайки, плейлисты, поиск, ссылки на mp3
  providers/ytmusic.js YouTube Music через youtubei.js: главная, лайки, плейлисты, радио, поток
  wave.js              смешивание волны: основа Яндекса + доля YTM из настроек
  stream.js            прокси аудио с Range: перемотка, кеш и обновление протухших ссылок
  lyrics.js            синхронизированные тексты из LRCLIB
  catalog.js           объединённые страницы исполнителя и альбома
  auth.js              окна входа
  store.js             настройки и зашифрованные секреты
src/preload.cjs        мост окна к главному процессу
src/renderer/          интерфейс (без фреймворков): app.js — экраны, player.js — очередь и плеер,
                       ribbon.js — живая лента волны, theme-mac.css — тема Liquid Glass
```

### Как собирается «Моя волна»

- Основа — сессия волны Яндекса с выбранными характером и настроением. Лайки, пропуски и дослушивания уходят в Яндекс, так что рекомендации учатся как в официальном приложении.
- Треки YouTube Music берутся из радио по случайным лайкнутым трекам YTM. При «Любимом» в поток попадают и сами лайки, при «Незнакомом» — только то, чего нет в лайках.
- Доля YTM (0–100%) задаётся в настройках. Если подключён только один сервис, волна строится из него.

## Что может сломаться

Оба сервиса подключены через **неофициальные** API.

- **Яндекс** (`providers/yandex.js`): без подписки Плюс полные треки могут не отдаваться. Сиды настроения (`settingMoodEnergy:*`, `settingDiversity:*`) взяты из того, что использует веб-клиент; если Яндекс их не примет, волна запустится без настроек.
- **YouTube** (`providers/ytmusic.js`): время от времени меняет защиту потоков. Приложение перебирает клиентов `ANDROID_VR → TV → YTMUSIC → WEB` и проверяет каждую ссылку. Если всё перестало играть, первым делом обнови библиотеку: `npm update youtubei.js`.

Ошибки главного процесса видны в терминале, где запущен `npm start`.
