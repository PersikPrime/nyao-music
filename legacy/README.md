# Nyao Legacy — состояние на 29.10.2026

Тонкий клиент Nyao Music для старых Android (4.1–4.4). Проверочное устройство — планшет пользователя 2014 года на Android 4.4 (едет в доставке); сейчас проверяем в эмуляторе Android Studio (API 19, x86).

## Решения
- **Платформа:** Android 4.1+ (`minSdk 16`). 4.0 не поддерживаем — в нём нет TLS 1.2.
- **Код:** отдельный проект `legacy/` в репозитории `PersikPrime/nyao-music` (ветка `nightly`). Java, без AndroidX и Kotlin, тема Holo, только сплошные цвета (без градиентов/блюра/теней). APK собирает GitHub Actions: workflow **Legacy APK** (`.github/workflows/legacy.yml`) → Artifacts → `NyaoLegacy-probe` / `NyaoLegacy`.
- **Сервисы:** Яндекс Музыка и YouTube Music. **SoundCloud и Spotify вырезаны** (не заработают). VK — не в первой версии.
- **Дизайн:** страница «Android 4+ · Legacy» в холсте «Мультиплеер — макеты»: вход по коду, главная (Моя волна, Мне нравится, Плейлисты, недавнее), боковое меню, плеер с тремя строками текста, экран «Нет связи», планшет 1280×800 в три колонки. Цвета: фон `#0B0B10`, панели `#16161D`/`#1F1F28`, текст `#F2F2F5`, вторичный `#9C9CAB`, акцент лавандовый `#CFC4FF`, полоска из трёх цветов волн (`#FFD60A`, `#F0574A`, `#CFC4FF`). Шрифт Roboto (системный).

## Что выяснили про сеть (проверено в эмуляторе 4.4)
1. Сертификаты: в 4.4 нет корней Let's Encrypt. Наши домены подписаны **YE1/YE2 → ISRG Root YE** (новое «поколение Y»), сервер присылает цепочку до ISRG Root X1.
2. Системный TLS 4.4: TLS 1.2 есть, но выключен; **нет AES-GCM**, а серверы (Cloudflare, наш) **не принимают CBC** — рукопожатие падает. Встроенный HTTP-клиент 4.4 после неудачи сам повторяет через SSLv3 и прячет настоящую ошибку.
3. **Решение, проверено:** свой TLS-движок **Conscrypt 2.5.2** (BoringSSL) в APK + свои корни в `assets/roots` (ISRG X1, X2, YE, YR; GTS R1/R3/R4). Результат: **TLS 1.3, TLS_AES_128_GCM_SHA256, HTTP 200** на `api.nmusic.bixtl.cc` и `api.music.withnyao.app`, ~120 мс. Работает и встроенный `HttpsURLConnection`, если дать ему фабрику сокетов Conscrypt.
4. Корни YE/YR сборка берёт с letsencrypt.org и проверяет (самоподписанный, `O=ISRG, CN=Root YE|YR`).

## Архитектура
- **Звук не идёт через сервер.** Как и в основном приложении: Яндекс — MP3 по токену (`/tracks/{id}/download-info` → `get-mp3`), YouTube — AAC m4a (itag 140) через мобильные клиенты InnerTube без расшифровки подписи. Оба формата `MediaPlayer` 4.4 играет сам.
- `MediaPlayer` 4.4 ходит в сеть системным TLS (не работает), поэтому внутри приложения — **локальный прокси на 127.0.0.1**: плеер берёт поток у него, прокси качает через Conscrypt (с поддержкой Range для перемотки).
- **Нагрузка на сервер:** почти ноль (вход по коду, проверка обновлений). Нагрузка на устройство: расшифровка потока 320 кбит/с.
- **Токены сервисов** на сервере не хранятся.

## Вход по коду (протокол)
1. Legacy создаёт пару ключей (RSA-2048) и вызывает `POST /legacy/pair` с открытым ключом → сервер отдаёт `id`, короткий код (`K7Q4MD`, 10 минут) и секрет опроса.
2. Пользователь вводит код в основном Nyao (Профиль → Устройства → «Подключить по коду»). Основное приложение получает открытый ключ устройства (`GET /legacy/pair/code/{code}`, нужен вход в Nyao), шифрует пакет (токены Яндекса и YouTube, сессия Nyao) **ключом устройства** (RSA-OAEP + AES-GCM) и отправляет `POST /legacy/pair/code/{code}`.
3. Legacy опрашивает `GET /legacy/pair/{id}?secret=…`, получает зашифрованный пакет, расшифровывает своим закрытым ключом. Сервер хранит пакет до получения или 10 минут, расшифровать его не может.

## План работ
1. Сервер: эндпоинты входа по коду (в памяти, с TTL и ограничением попыток) + тесты.
2. Legacy-клиент: TLS-слой (готов), вход по коду, главная, «Мне нравится», поиск, плеер с прокси, уведомление/экран блокировки, строки текста.
3. Основное приложение (Android + ПК): экран «Подключить по коду» и шифрование пакета. *Без этого вход в legacy не завершится.*
4. Проверка на планшете (ARM-версия Conscrypt).

## Что важно не забыть
- Отладочная подпись меняется каждую сборку: перед установкой `adb uninstall org.nyao.legacy`. Для постоянной подписи — отдельный ключ в секретах.
- Установка в эмулятор 4.4 только через `adb install` (перетаскивание в Studio падает на `--user`).
- SDK пользователя перенесён на `F:\Android\Sdk`, эмуляторы — `F:\Android\avd`.
